# Diff Society Website

Responsive static website for Diff Society, ready for GitHub Pages.

## Pages
- `index.html` — Home
- `about/index.html` — About
- `bbcode/index.html` — BBCode library
- `me-section/index.html` — Me! Section preview, BBCode, and copy button
- `map-description/index.html` — Beatmap description preview, BBCode, and copy button

## Assets
- `assets/diff-society-logo.png` — Diff Society logo
- `assets/me-section-preview.jpg` — Me! Section preview supplied by the site owner
- `assets/map-description-preview.png` — Beatmap description preview supplied by the site owner

## Publish with GitHub Pages
Upload the contents of this folder to the root of your `DiffSociety.github.io` repository. Then open Settings → Pages and select **Deploy from a branch**, branch `main`, folder `/ (root)`, and save.

The public website URL should be `https://diffsociety.github.io/`.

## Updating the site
When you change a file, upload the replacement file to the same location in GitHub and commit the change. Keep the folder structure intact.
