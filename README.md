# Diff Society Website

A responsive, dark red/black website for the Diff Society osu! mapping community.

## Publish on GitHub Pages
1. Upload the contents of this folder to the root of `DiffSociety/diffsociety.github.io`.
2. Commit the files to the `main` branch.
3. In Settings → Pages, use Deploy from a branch, `main`, and `/(root)`.
4. Visit https://diffsociety.github.io after GitHub Pages finishes deploying.

## Pages
- `/` Home
- `/about/` About Diff Society
- `/bbcode/` BBCode Library
- `/me-section/` Me! section BBCode
- `/map-description/` Beatmap description BBCode
