Beatmap Description BBCode

Adding the Diff Society banner to your map is a simple way to share the community with other players and mappers who might want to collaborate, find guest difficulties, or learn how to map. The logo is an image map, so players can click it directly in your beatmap description to visit the Diff Society website.

Preview of how the BBCode will look in your beatmap description.

Copy the BBCode

[notice][centre]
[imagemap]
https://blex.s-ul.eu/Mxmc221D
0 0 100 100 https://diffsociety.github.io Diff Society Website
[/imagemap][/centre][/notice]

How to use it: Click Copy BBCode, open your beatmap's description editor on osu!, paste the code, and save your changes.
